## 目标

实现基于 IP 的简单多用户管理，限制每个用户每天的任务数量，防止滥用。

---

## 核心设计

### 1. 用户标识

**方案**: 直接使用客户端 IP 地址作为用户 ID

**优点**:
- 无需登录/注册，零摩擦
- 无需维护用户表
- 实现简单

**实现**:
```python
# FastAPI 获取客户端 IP
client_ip = request.client.host
# 或通过 X-Forwarded-For 头获取真实 IP（如果有反向代理）
client_ip = request.headers.get("X-Forwarded-For", request.client.host)
```

---

### 2. 配额限制

**默认限制**: 每用户每天 **5 个任务**

**任务计数**:
- 上传文件 = 1 个任务
- 提交 URL = 1 个任务
- 追问对话 = **不计入**（鼓励互动）
- 全局聊天 = **不计入**

**配额检查时机**: 仅在任务提交时（`/api/upload` 和 `/api/submit-url`）

---

### 3. 白名单机制

**配置方式**: 在 `.env` 或环境变量中配置白名单 IP 列表

```env
# .env
QUOTA_WHITELIST_IPS=192.168.1.100,10.0.0.50,172.16.0.1
DAILY_TASK_LIMIT=5
```

**白名单用户**: 不限制任务数量，直接跳过配额检查

---

### 4. 数据存储

**方案**: JSON 文件存储配额数据（轻量、无需数据库）

**文件路径**: `data/quota_usage.json`

**数据结构**:
```json
{
  "2026-10-06": {
    "192.168.1.50": {
      "count": 3,
      "tasks": ["task_id_1", "task_id_2", "task_id_3"],
      "last_used": "2026-10-06T14:30:00"
    },
    "10.0.0.25": {
      "count": 1,
      "tasks": ["task_id_4"],
      "last_used": "2026-10-06T10:15:00"
    }
  }
}
```

**自动清理**: 每天首次访问时，清理 7 天前的数据

**3.2 获取客户端 IP 的辅助函数**:

```python
def get_client_ip(request: Request) -> str:
    """获取客户端真实 IP（支持反向代理）"""
    forwarded = request.headers.get("X-Forwarded-For")
    if forwarded:
        return forwarded.split(",")[0].strip()
    return request.client.host
```

**3.3 配额检查中间件/依赖**:

```python
def check_quota_dependency(request: Request):
    """配额检查依赖，用于路由"""
    client_ip = get_client_ip(request)
    allowed, info = quota_manager.check_quota(client_ip)
    if not allowed:
        raise HTTPException(
            status_code=429,
            detail={
                "message": "今日任务数量已达上限",
                "used": info["used"],
                "limit": info["limit"],
                "reset_time": "明天 00:00"
            }
        )
```

```python
@app.get("/api/quota")
async def get_quota(request: Request):
    """查询当前用户的配额使用情况"""
    client_ip = get_client_ip(request)
    info = quota_manager.get_usage_stats(client_ip)
    return {
        "ip": client_ip,
        "used": info["used"],
        "limit": info["limit"],
        "remaining": info["remaining"],
        "is_whitelisted": client_ip in quota_manager.whitelist,
    }
```

## 安全考虑

### 1. IP 伪造防护

**问题**: 客户端可以伪造 `X-Forwarded-For` 头

**方案**: 
- 仅在已知有反向代理时信任 `X-Forwarded-For`
- 配置项 `TRUST_PROXY_HEADERS=false`（默认不信任）

```python
def get_client_ip(request: Request, trust_proxy: bool = False) -> str:
    if trust_proxy:
        forwarded = request.headers.get("X-Forwarded-For")
        if forwarded:
            return forwarded.split(",")[0].strip()
    return request.client.host
```

### 2. 数据隐私

- 仅存储 IP 地址和使用计数，不存储其他个人信息
- 数据文件仅本地访问，不上传
- 7 天自动清理
