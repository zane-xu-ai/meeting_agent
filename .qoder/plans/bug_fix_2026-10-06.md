### 1. Rerank API 404 错误 ✅ 已修复

**问题描述**:
- 日志显示 `[Rerank] HTTP 错误: 404` 
- URL: `https://dashscope.aliyuncs.com/compatible-mode/v1/rerank`

**修复方案**:
- 文件: `agent/reranker.py:42`
- 修改前: `self.rerank_url = f"{self.base_url}/rerank"`
- 修改后: `self.rerank_url = "https://dashscope.aliyuncs.com/api/v1/services/rerank/text-rerank/text-rerank"`
- 参考: DashScope 官方文档

**验证**:
- 服务器已重启并加载新代码
- 下次全局聊天时将使用正确的 Rerank 端点

### 2. LLM 返回空回复导致前端卡住 ✅ 已修复

**问题描述**:
- 用户提问"视频总字数是多少..."后，前端一直显示加载中
- 日志显示: `reply=0 chars, rounds=1, messages=2, tokens=7`
- 前两个模型返回 403 Forbidden（免费额度耗尽）
- 第三个模型返回 `completion_tokens=2048` 但内容为空

**根本原因**:
1. **API 额度问题**: qwen3.7-flash 系列模型返回 403，说明免费额度已耗尽
2. **max_tokens 限制**: 使用 `max_tokens=2048`，模型可能达到限制后返回空内容
3. **缺少空回复检测**: 代码未检查 LLM 返回是否为空，直接传递给前端

**修复方案**:

#### 2.1 提升 max_tokens 限制
- 文件: `server.py` (3 处)
  - 任务追问对话: `/api/chat/{task_id}` (line 787)
  - 全局聊天: `/api/global-chat` (line 953)
  - 全局聊天流式: `/api/global-chat/stream` (line 1041)
- 修改: `max_tokens=2048` → `max_tokens=4096`

#### 2.2 添加空回复检测
```python
# 检查空回复
if not reply or not reply.strip():
    logger.warning(f"[任务 {task_id}] LLM 返回空回复")
    reply = "抱歉，我暂时无法回答这个问题。请稍后重试，或者尝试换一种提问方式。"
```

**影响范围**:
- 任务追问对话 (`/api/chat/{task_id}`)
- 全局聊天 (`/api/global-chat`)
- 全局聊天流式输出 (`/api/global-chat/stream`)

## 技术细节

### DashScope Rerank API 端点

**正确的端点**:
```
POST https://dashscope.aliyuncs.com/api/v1/services/rerank/text-rerank/text-rerank
```

**请求格式**:
```json
{
  "model": "qwen3.7-text-rerank",
  "input": {
    "query": "查询文本",
    "documents": ["文档1", "文档2", ...]
  },
  "parameters": {
    "top_n": 5,
    "return_documents": false
  }
}
```

**参考文档**:
- [阿里云百炼 - 文本排序](https://help.aliyun.com/document_detail/2780057.html)

### 空回复检测逻辑

**检测条件**:
```python
if not reply or not reply.strip():
    # 返回友好提示
```

**原因**:
- `not reply`: 检测 None 或空字符串
- `not reply.strip()`: 检测只包含空白字符的字符串（空格、换行等）
