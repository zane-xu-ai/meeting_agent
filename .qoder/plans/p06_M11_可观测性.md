## 目标

通过 LangSmith 实现全链路追踪，记录 LangGraph 每个节点的执行轨迹，方便调试和性能优化。

---

## 核心设计

### 1. 技术选型

**LangSmith** — LangChain 官方提供的可观测性平台

**优势**:
- LangGraph 内置支持，零代码侵入
- 自动记录每个节点的输入/输出/耗时
- 可视化执行轨迹图
- Token 用量统计
- 错误追踪和告警

### 2. 追踪内容

| 节点 | 记录内容 |
|------|----------|
| `extract_audio` | 视频 URL/路径、提取耗时、输出音频路径 |
| `preprocess` | 预处理参数、输出 WAV 路径 |
| `asr_transcribe` | ASR 模型、转写耗时、转写字符数 |
| `text_clean` | 清洗前后字符数对比 |
| `agent_loop` | Function Calling 调用链、Tool 选择、LLM 耗时 |
| `format_output` | 输出文件路径、结果长度 |

### 3. 配置方式

通过环境变量或 `.env` 文件配置：

```env
# LangSmith 追踪配置
LANGSMITH_API_KEY=lsv2_pt_xxx
LANGCHAIN_PROJECT=meeting_agent
LANGCHAIN_TRACING_V2=true
```

**集成方式**: 导入 tracing 模块，触发自动初始化


## 使用方式

### 1. 启用追踪

在 `.env` 中配置：

```env
LANGSMITH_API_KEY=lsv2_pt_xxx
LANGCHAIN_PROJECT=meeting_agent
LANGCHAIN_TRACING_V2=true
```

### 2. 查看追踪数据

访问 LangSmith 控制台：https://smith.langchain.com/

在项目 `meeting_agent` 下可以看到：
- 每次任务执行的完整轨迹
- 每个节点的输入/输出
- 执行耗时分布
- Token 用量统计
- 错误堆栈

### 3. 禁用追踪

设置 `LANGCHAIN_TRACING_V2=false` 或不配置 `LANGSMITH_API_KEY`。
